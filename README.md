# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ企業サイトです。
HTML・CSS・JavaScript を `index.html` 1ファイルにまとめているため、ビルドやサーバーは不要です。

## 概要

ページは次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| トップ | キャッチコピーと、航空障害灯が点滅するビル群のイラスト |
| 事業内容 | ビルのフロア案内になぞらえた4つの事業（クラウド基盤設計、業務システム開発、モバイルアプリ開発、保守・運用） |
| 導入実績 | 代表的な3件の事例と成果の数値 |
| 開発の進め方 | 測量 → 設計 → 施工 → 竣工・運用の4工程 |
| 会社概要 | 会社情報の表と代表メッセージ |
| お問い合わせ | 連絡先と入力チェック付きのフォーム |

主な仕様:

- ライトテーマとダークテーマに対応しています（OS の設定に従います）。
- スマートフォンの画面幅でも表示が崩れないレイアウトです。
- フォントは Google Fonts から読み込みます。オフラインのときは OS 標準のフォントで表示されます。
- お問い合わせフォームはデモのため、実際には送信されません。

> 掲載している会社情報（代表者名、所在地、連絡先、実績の数値など）はすべて架空のものです。

## ブラウザで開く手順

### エクスプローラーから開く（Windows）

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。既定のブラウザでページが表示されます。
3. 別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選びます。

### コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

macOS の場合は `open index.html`、Linux の場合は `xdg-open index.html` を使います。

### ブラウザにドラッグ＆ドロップする

開いているブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても表示できます。
